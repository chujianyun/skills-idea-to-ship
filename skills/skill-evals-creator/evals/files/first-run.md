# 合成的首轮材料

以下内容是用于评测创建助手的模拟反馈，不是本技能实际运行报告。

## 被测技能规则

meeting-actions 把会议记录转成 Markdown 行动项表，列为事项、负责人、截止时间；未给出的字段写“待定”，只使用原文事实，相对日期保留原文。

## 原始用例

```json
{
  "skill_name": "meeting-actions",
  "evals": [
    {
      "id": 7,
      "prompt": "整理行动项：林禾说她周五交访谈结论；演示页也要更新，但负责人和时间都没定。",
      "expected_output": "两项行动项。访谈结论负责人为林禾、截止时间为周五；演示页更新负责人和截止时间均为待定。",
      "files": [],
      "user_tag": "keep-for-regression"
    }
  ]
}
```

## 模拟输出

| 事项 | 负责人 | 截止时间 |
|---|---|---|
| 整理访谈结论 | 林禾 | 周五 |
| 更新演示页 | 林禾 | 待定 |

## 人工反馈

演示页没人认领，模型却把上一项的负责人填过来了。其他项目是否正确也要按材料核对，不因为这次只反馈一个问题就自动判为全通过。
