# Meeting Actions（合成测试技能）

1. 从用户提供的会议记录提取明确提到的行动项，输出 Markdown 表格，列为事项、负责人、截止时间。不添加原文没有的任务。
2. 负责人或截止时间未明确时填写“待定”，不能从附近出现的人名推测负责人。已明确的信息必须保留。
3. 空白记录或纯闲聊没有行动项时，说明没有可提取的行动项，不虚构任务。
4. 只有任务要求、未提供记录或所指记录文件不存在时，说明缺少记录并请求补充，不编造会议内容。
5. 请求纯情绪分析时，说明本技能只提取行动项，不编造情绪结论。

本技能未规定表格行顺序，也未规定同一行动项出现互相冲突的截止时间时如何取舍。
